Private AI tools
I run myself.

One Linux laptop, a dozen Docker containers, and AI models that run locally: no cloud bills, no data leaving the house. Everything is reachable only over my private network, documented, and backed up nightly.

Built for my classes

Class Notes

Tap a class on your phone to record a lecture. Audio uploads while you record (nothing lost if the battery dies), a local Whisper model transcribes it, and a local LLM writes structured study notes. No cloud AI.

Study Library

A home for the flashcards and quizzes I generate with Claude. It runs each one in a sandbox and implements Claude’s artifact storage API itself, so progress saves to my server and follows me across devices, with streaks, a heatmap and nightly backups to GitHub.

Minecraft server + admin panel

A Bedrock server friends can join from the internet or the apartment Wi-Fi, locked down in layers: one forwarded port, per-IP flood limits (IPv4 and IPv6), and a contained server process. Managed from a phone-friendly panel for players, permissions, settings and a live console.

How it’s run

Operated like a real environment

🔒 Private by default: apps bind to localhost; access only through Tailscale with HTTPS.

♻️ Self-healing: containers restart on crash and boot; queues recover after restarts.

📘 Documented: every service has a rebuild runbook and decision log in Git.

💾 Backed up: nightly exports to GitHub; world and data backups.
