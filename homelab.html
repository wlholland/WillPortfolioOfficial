Homelab

Things I run at home.

One Linux laptop, a set of Docker containers, and AI models that run locally. No cloud bills, and nothing leaves my private network.

Every service binds to localhost and is reached only through Tailscale with HTTPS. Each one has a rebuild runbook in Git, restarts itself after crashes and reboots, and gets backed up nightly.

Services

05 running

01   Class Notes

Record a lecture, get study notes.

Tap a class on my phone to record. Audio uploads in five-second pieces while I record, so nothing is lost if the battery dies. A local Whisper model transcribes it and a local LLM writes structured notes.

  • FastAPI
  • SQLite
  • MediaRecorder
  • Whisper
  • Ollama
  • Docker

02   Study Library

A home for the study tools I make with Claude.

Flashcards and quizzes I generate with Claude run here in a sandbox. The library implements Claude’s artifact storage API itself, so progress syncs across devices. It tracks real study time (idle tabs don’t count) as a daily streak and heatmap, and commits everything to GitHub every night.

  • FastAPI
  • SQLite
  • JavaScript
  • CSP sandbox
  • cron + git

03   Game server

A public server, locked down in layers.

A Minecraft Bedrock server friends join from the internet or our apartment Wi-Fi. One forwarded port, per-IP flood limits for IPv4 and IPv6, and a contained server process. I manage it from a phone-friendly admin panel: players, permissions, settings and a live console.

  • Docker
  • iptables
  • FastAPI
  • WebSockets
