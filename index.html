03 · Consulting

Case studies from the field.

From NetworkPC, the managed IT practice I run with my father. Client details are anonymized.

Microsoft 365 · Incident response

Stopping an email compromise, then hardening the tenant

  1. Investigate: traced a business-email-compromise attempt through sign-in and audit logs: suspicious sign-ins, forwarding and inbox rules.
  2. Contain: revoked sessions, reset credentials, removed malicious rules and confirmed nothing else was touched.
  3. Harden: enforced MFA and Conditional Access, blocked legacy sign-in, tightened mail and sharing policies.
  4. Prevent: documented the playbook and walked the owner through the warning signs, so the next attempt gets reported, not paid.
Intune · Autopilot · Entra ID

Zero-touch laptops: an Intune & Autopilot rollout

  1. Design: Autopilot enrollment, Entra ID join, and Conditional Access requiring compliant devices.
  2. Package: line-of-business apps as Win32 packages with detection rules, and policies as configuration profiles.
  3. Automate: PowerShell remediation scripts for drift, plus staged Windows update rings (pilot → broad).
  4. Result: a new laptop goes from box to ready-to-work with no hands-on imaging; phones covered with Android Enterprise.
